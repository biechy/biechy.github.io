Introduction

Feature Space

The feature space X\mathcal XX. Usually X=Rd\mathcal X=\mathbb R^dX=Rd but you can also have qualitative variable.

Target Space

The target space Y\mathcal YY. It can be ever compact R\mathbb RR or countable N\mathbb NN.

Dataset

A dataset is a couple Dn:=(Xi,Yi)\mathcal D_n:=(X_i, Y_i)Dn​:=(Xi​,Yi​) where Xi,YiX_i, Y_iXi​,Yi​ r.v from X,Y\mathcal X,\mathcal YX,Y

Note

You can split a dataset in a train and a test dataset or a train, a validation and a test dataset.

Hypothesis class

The hypothesis class is the set H={h:X→Y;h measurable }\mathcal H = \{h : \mathcal X \rightarrow \mathcal Y; h \text{ measurable }\}H={h:X→Y;h measurable } with hhh a predictor.

Learning rule

A learning rule is a mapping from training data to hypotheses in a given hypothesis class, i.e h^:Dn→H\hat h : \mathcal D_n \rightarrow \mathcal Hh^:Dn​→H

Note

By habit, we will not note the conditioning to the dataset of the learning rule: h^(Dn)(x):=h^(x)\hat h (\mathcal D_n)(x):=\hat h (x)h^(Dn​)(x):=h^(x)

Loss function

A loss function is ℓ:Y×Y→R+\ell : \mathcal Y \times \mathcal Y \rightarrow \mathbb R^+ℓ:Y×Y→R+

Risk

The risk of a predictor is R(h^)=E(ℓ(h^(X),Y))R(\hat h) = \mathbb E(\ell(\hat h(X), Y) )R(h^)=E(ℓ(h^(X),Y))

Note

Depending the dataset that you use (i.e train, validation, test) you can have different type of risk. The most important is the generalization one with the test dataset.

Empirical risk

Most of time, we don’t know the law of the data so we need to estimate R(h^∣Dn)R(\hat h|\mathcal D_n)R(h^∣Dn​) with R^(h^)=1n∑iℓ(h^(xi),yi)\hat{\mathcal R}(\hat h)=\frac{1}{n}\sum_i\ell(\hat h(x_i),y_i)R^(h^)=n1​∑i​ℓ(h^(xi​),yi​)

Note

You can also estimate R(h^)R(\hat h)R(h^) via cross validation, bootstrap, etc.

The bayes risk is the best possible risk from the hypothesis class, i.e R∗=inf⁡h∈HE(ℓ(h(X),Y))\mathcal R^* = \inf_{h \in \mathcal H}\mathbb E(\ell(h(X), Y) )R∗=infh∈H​E(ℓ(h(X),Y))

Excess risk

The excess risk is R(h)−R∗R(h)-R^*R(h)−R∗
