Regression

A regression function is the estimation of E(Y∣X)\mathbb E(Y|X)E(Y∣X).

Proposition

The regression minimize the quadratic risk R(h)=E((h(X)−Y)2)\mathcal R(h)=\mathbb E((h(X)-Y)^2)R(h)=E((h(X)−Y)2)

Proof
R(h)=E((h(X)−Y)2)=E((h(X)−E(Y∣X)+E(Y∣X)−Y)2)=E((h(X)−E(Y∣X))2+(E(Y∣X)−Y)2+2(h(X)−E(Y∣X))(E(Y∣X)−Y))=E((h(X)−E(Y∣X))2)+E((E(Y∣X)−Y)2)+2E((h(X)−E(Y∣X))(E(Y∣X)−Y))=E((h(X)−E(Y∣X))2)+R(E(Y∣X))+0≥R(E(Y∣X))\begin{align*} R(h) &= \mathbb E((h(X)-Y)^2)\\ &= \mathbb E((h(X)-\mathbb E(Y|X)+\mathbb E(Y|X)-Y)^2) \\ &= \mathbb E((h(X)-\mathbb E(Y|X))^2+(\mathbb E(Y|X)-Y)^2+2(h(X)-\mathbb E(Y|X))(\mathbb E(Y|X)-Y)) \\ &= \mathbb E((h(X)-\mathbb E(Y|X))^2)+\mathbb E((\mathbb E(Y|X)-Y)^2)+2\mathbb E((h(X)-\mathbb E(Y|X))(\mathbb E(Y|X)-Y)) \\ &= \mathbb E((h(X)-\mathbb E(Y|X))^2)+R(\mathbb E(Y|X))+0 \geq R(\mathbb E(Y|X)) \end{align*}R(h)​=E((h(X)−Y)2)=E((h(X)−E(Y∣X)+E(Y∣X)−Y)2)=E((h(X)−E(Y∣X))2+(E(Y∣X)−Y)2+2(h(X)−E(Y∣X))(E(Y∣X)−Y))=E((h(X)−E(Y∣X))2)+E((E(Y∣X)−Y)2)+2E((h(X)−E(Y∣X))(E(Y∣X)−Y))=E((h(X)−E(Y∣X))2)+R(E(Y∣X))+0≥R(E(Y∣X))​

So the minimum is obtain for h(X)=E(Y∣X)h(X)=\mathbb E(Y|X)h(X)=E(Y∣X)

Linear Regression

Suppose that the target follow Y=X⊤β+εY = X^\top \beta + \varepsilonY=X⊤β+ε with:

  1. linear expectation in β\betaβ : E(Y∣X)=X⊤β\mathbb E(Y|X) = X^\top \betaE(Y∣X)=X⊤β
  2. centered error : E(ε∣X)=0\mathbb E(\varepsilon | X) = 0E(ε∣X)=0
  3. variance of the error is constant : var(ε∣X)=σ2var(\varepsilon | X) = \sigma^2var(ε∣X)=σ2
  4. independence of the error: cov(εi,εj∣Xi,Xj)=0cov(\varepsilon_i, \varepsilon_j|X_i, X_j) = 0cov(εi​,εj​∣Xi​,Xj​)=0

Note

The hypotesis class is H:={hβ(x)=x⊤β∣β∈Rp}\mathcal H := \{ h_\beta(x) = x^\top \beta | \beta \in \mathbb R^p \}H:={hβ​(x)=x⊤β∣β∈Rp}. We can also denote x⊤β=ηx^\top \beta=\etax⊤β=η.

Suppose that the target follow Y=X⊤β+εY = X^\top \beta + \varepsilonY=X⊤β+ε with:

  1. linear expectation in β\betaβ : E(Y∣X)=X⊤β\mathbb E(Y|X) = X^\top \betaE(Y∣X)=X⊤β
  2. errors follow ε∼N(0,σ2)\varepsilon \sim \mathcal N(0, \sigma^2)ε∼N(0,σ2) iid

When to do a linear regression ? For each couple of variables do a scatter plot and if you see a linear correlation with the target for a lot of features, bingo ! Be careful, if two features are “strongly” correlate you can drop one.

Intercept

We can add a feature equal to 111 for each data because, for now, the line go through the origin. With the intercept we add a new estimator β0\beta_0β0​ that represent the height at the origin of the line.

Tips

Normalize the features is not mandatory but it can be interesting if you want to compare the elements of β\betaβ. It can also help for numerical stabilization.

Estimation
